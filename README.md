# 🟣 Нектус — Nectus

**Соединяй, обменивайся, растите вместе**

Нектус — социальная платформа для межпоколенческого диалога, обмена навыками и создания близкого круга общения.

## ✨ Возможности

- 📖 **Река Впечатлений** — истории людей разных поколений
- 🔄 **Обмен навыками** — учись и учи без денег
- 💫 **Мой Круг** — приватное пространство для близких
- 💬 **Чаты** — общение в реальном времени
- 🌙 **Тёмная тема** — комфорт в любое время суток
- ⏳ **Капсулы времени** — послания в будущее

##  Технологии

- HTML5, CSS3, JavaScript (ES6+)
- Supabase (база данных + авторизация)
- GitHub Pages (хостинг)
